# EVGA 프로필 공개 상태

[English](PUBLICATION-STATUS.en.md)

해당 시스템의 사용자 입회 잠금 해제는 입증되었습니다. PR 검토는 가능하지만 재사용 가능한 USB 없는 잠금 해제 프로필은 아직 완성되지 않았습니다.

2026-10-29 기여자의 검사에서 SULK01 해시, 슬롯 8, 트랜잭션 반환, 자원 해제, Windows 준비 이벤트, 두 캡처 및 원본 USB 예약 내용이 모두 일치했습니다. 예약과 실행 증거는 각 볼륨에 보존됩니다. 기록은 초기화하지 않았으며 슬롯 9는 빌드 전용입니다.

임시 펌웨어 항목 정리가 성공했고 후속 검사에서 항목 부재와 빈 BootNext가 확인되었습니다. 원본 부팅 항목은 백업과 일치했습니다. 이것만으로 일반적인 복구나 이전 오류의 원인이 입증되지는 않습니다.

완료 전 남은 작업:

- 정리 후 USB 제거 여부와 정상 Limine 및 Windows 부팅 확인.
- 성능 측정이 잠금 해제 후 재부팅 없이 수행되었는지 확인.
- 예약 초기화나 재실행 없이 검토된 증거로 볼륨 간 시도 기록 진행 구현.
- USB 없는 잠금 해제 실행, 일회성 제한, 증거 수집 및 정리 경로 통합과 실제 시스템 검증.
- 새 정리 실행 경로, 네이티브 삭제 인자 및 부분 실패 회귀 검사 추가. 기존 18개 모의 검사는 새 실행 경로를 포함하지 않습니다.
- 오래된 안내 문구 정리, 영문·한국어 최종 안내 및 관리자 검토 완료.

2026-10-29 로컬 준비 래퍼 및 펌웨어 진입 스크립트 모의 검사가 통과했습니다. 기여자 빌드의 PE 검사와 24개 호스트 검사도 통과했습니다. 이는 USB 없는 실제 잠금 해제를 입증하지 않습니다.
