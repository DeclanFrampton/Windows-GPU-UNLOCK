# SULK02 결과와 다음 단계

[English](SULK02-RESULT.en.md)

업로드된 로그는 슬롯 9, 성공한 트랜잭션 반환, 자산 해제, 종료, Windows 준비 및 완전한 캡처 2회를 기록합니다. Movian은 예상 확인 화면과 정상 Windows 부팅을 보고했습니다. [검사 결과와 해시](sulk02-result.json). USB 미연결 확인과 같은 세션의 벤치마크는 아직 필요합니다.

증거 ZIP 생성은 성공했지만 정리는 `BootOrder changed; preserve backup and stop`으로 거부되었습니다. 정리는 완료되지 않았으며 현재 순서나 변경 원인은 아직 검사하지 않았습니다. 이전 감사 시험의 원인과 같다고 가정하지 않습니다. 비공개 백업과 임시 펌웨어 항목을 보존하고 정리나 EFI를 재시도하지 마세요.

**다음 단계는 벤치마크입니다. Cancel은 실행하지 마세요.** Cancel은 부팅 전 취소용 선택지이며 부팅 후 필수 단계가 아닙니다. 브랜치를 업데이트하고 GPU 작업을 닫고 설정을 유지한 뒤 저장소 루트에서 명령 하나만 실행하세요.

```powershell
./research/profile/benchmark-shared-esp-second.ps1
```

검토된 기준 실행 파일을 그대로 사용하여 기존 3회/4모드 벤치마크를 실행하고 출처 자료가 포함된 ZIP 하나를 만듭니다. 재빌드, 펌웨어/설정 변경, 정리 또는 재부팅은 하지 않습니다. GPU 부하/열 증가나 드라이버/앱 오류가 발생할 수 있습니다. 오류가 나면 오류를 보내고 재빌드나 자동 재시도는 하지 마세요.

마지막에 출력되는 ZIP을 보내고 SULK02 부팅 중 USB가 빠져 있었는지와 그 후 재부팅 여부를 알려주세요. 측정 전에 재부팅하지 마세요. 이미 재부팅했다면 그대로 보고하세요. 현재 상태 측정은 가능하지만 같은 SULK02 세션의 증거로 주장할 수 없습니다.

로컬 모의 실행에서 ZIP/출처 자료 생성, 실행 파일 변경 거부 및 이전 결과 재사용 거부를 확인했습니다. 실제 GPU 작업이나 펌웨어 API는 실행하지 않았습니다. 펌웨어 정리는 변경 상태를 검사한 후 별도로 처리합니다.
