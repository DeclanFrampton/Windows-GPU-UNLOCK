# 기존 인벤토리와 소스 ID 범위 비교

기존 수집기 인벤토리를 일반 프로브 장치 목록 및 고정 프로필 장치/서브시스템과
비교합니다. 프로필 선택, Windows 조회 또는 플래시된 서브시스템으로 물리 PCB
제조사 추론을 하지 않습니다. 고정 ID 일치도 보드/BIOS/PROM/토폴로지 검증은 아닙니다.

```powershell
powershell -NoProfile -File .\research\profile\test-inventory-source-scope.ps1
```
기존 inventory.json을 입력합니다. 기존 Python만 필요하며 설치/컴파일러/관리자 권한은
필요하지 않습니다. 예상 source-scope.json은 요청 시 검토 후 반환합니다.
-OutputRoot로 기존 로컬 쓰기 가능 폴더를 지정할 수 있습니다. 알 수 없음/오류 시
원본 보존 후 중지합니다. 새 인벤토리/캡처, 설정/VBIOS 변경, EFI 준비/부팅 또는
다른 기기의 프로필 사용을 하지 않습니다.

22의 기존 보고서는 물리 ASUS TUF OC3070Ti에 MSI Suprim X VBIOS를 설치했다고
보고하며2482/50511462입니다. B660M3070Ti 고정 프로필의 장치 ID는 같지만
서브시스템은50521462이며 B460M DS3H/F8a/10400F도 다른 기기입니다.
2482는 일반 probe_device_ids에 없습니다. 이 관찰로 고정 프로필이나 자동 프로브
경로를 허용하지 않습니다. 원래 ASUS94.04.65.00.3E/현재 MSI94.04.65.00.2C 이력은
소유자 보고이며 복원/플래시 실험을 요청하지 않습니다.

테스트 메서드3개는 같은 장치/다른 서브시스템, 정확한 ID지만 기기 미허용,
알 수 없는 범위/ID 거부를 검사합니다. 실제22기존 인벤토리 및 PowerShell 출력도
로컬 통과했습니다. 소스 목록/문서 비교이며 하드웨어 또는 VBIOS 출처 증명이 아닙니다.
이미 계산했으므로 확인용 추가 파일/재실행은 필요하지 않습니다.
