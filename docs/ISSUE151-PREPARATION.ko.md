# 이슈 151: 그래프 준비 범위

보고된 구성은 X570 AORUS ELITE / F40 / Ryzen 5800X, OCuLink의 헤드리스
Gigabyte RTX 3080 `2216/403F1458`, 화면이 연결된 ASUS RTX 5080
`2C02/89E01043`입니다. 잠긴 상태의 벤치마크 3회는 기준값이며 잠금 해제
결과가 아닙니다. Windows 경로는 부팅 전 소유권이나 OCuLink 펌웨어
경로를 입증하지 않습니다.

`graph-configurations/issue151.json`은 두 PCI 장치의 정확한 ID를 기록합니다.
소프트웨어 화면 4개는 알려진 어댑터로 추가하지 않았습니다. 이름과 버전만으로
열거자, 서명된 공급자, 펌웨어 ID를 확인할 수 없습니다. ROOT/SWD를 포함한
알 수 없는 ID는 계속 준비를 거부합니다. 어댑터 제거 또는 가드 우회는 하지
마세요. 설정 데이터로 MMIO, 장치 해제 또는 잠금 해제를 활성화할 수 없습니다.
PR118의 정확한 카드 심층 읽기 제안은 별개이며 X570-F 설계를 이 보드에
옮길 수 없습니다.

고정된 소스 체크아웃에서 선택적으로 CPU 전용 회귀 테스트를 실행합니다.

```powershell
powershell -NoProfile -File .\research\profile\test-graph-configurations.ps1 -Report
```

신뢰된 픽스처를 읽고 Documents에 새 보고서를 만듭니다. 하드웨어 인벤토리
읽기, 의존성 설치, USB 준비 또는 EFI 부팅은 하지 않습니다. 예상 결과는
PASS 및 `Passed=true`, 물리 어댑터 핀 2개, 알 수 없는 화면 거부 6개,
하드웨어/허용/쓰기 플래그가 모두 false인 `graph-configuration.json`입니다.
재현한다면 이 JSON만 공유하세요. 관리자는 이미 실행했습니다. 새 캡처는
필요하지 않습니다.

실패하거나 하드웨어/허용/쓰기 플래그가 예기치 않게 true이면 중단하세요.
보고서와 현재 설정을 유지하고 하드웨어 재시도, 재부팅 또는 어댑터 제거를
하지 마세요. 소프트웨어 화면 ID 검토 전까지 실제 장비 그래프 준비는 대기
상태입니다. 확인할 수 없는 정보는 그대로 unknown으로 둬도 됩니다.
이 문서는 참석형 실행을 제안하지 않습니다.
