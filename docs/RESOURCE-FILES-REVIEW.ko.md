# 기존 리소스 파일 통합 검토

기존 생산 FWSEC 파서와 캡처 드라이버 검토기를 한 명령으로 실행합니다.
성공한 기존 PROM/DIAG/IMG를 읽으며 프로필 생성 또는 호환성 범위를 변경하지
않습니다. 드라이버 관찰/목록 일치는 서명 신뢰, 소유권, 해제, 하드웨어 증명 또는
쓰기 허가가 아닙니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\research\profile\test-resource-files.ps1
```
기존 캡처 폴더를 입력합니다. Windows에 이미 설치된 Python과 LLVM/MSVC만
사용합니다. 도구가 없으면 설치나 PATH/설정 변경 없이 중지합니다.
새 Documents 폴더의 resource-files.json이 예상 결과입니다. -OutputRoot로
기존 로컬 쓰기 가능 폴더를 지정할 수 있습니다. 검토한 JSON만 반환하고 원시
파일/백업은 로컬에 보관합니다. PROM 발견/미발견 및 드라이버 관찰/누락/잘못됨
모두 유용한 결과입니다. 오류나 불완전 결과 시 중지합니다. 파일 대체, 프로필
생성, 준비, 펌웨어/디스플레이 설정 변경 또는 캡처/부팅 반복을 하지 않습니다.
하드웨어 작업은 허용하지 않습니다.

로컬 검증은 빈 합성 PROM에 실제 생산 파서를 사용하며 드라이버 누락,
해시 보존/개인정보 및 기존 드라이버 정상/손상/누락/중복 검사를 포함합니다.
기여자의 실제 하드웨어/파일은 여기서 독립적으로 다시 실행하지 않았습니다.
두 검사가 필요한 사례에는 개별 반복 대신 이 통합 검사를 사용합니다.

준비 일관성: 리소스 준비도 그래프 준비처럼 검토되지 않은 ROOT/SWD 디스플레이를 조용히 무시하지 않고 거부합니다. 서명 여부만으로 정확한 ID가 고정되지 않습니다. 기존 서명 LCI 조건은 유지합니다. ROOT/SWD/Punktfunk 서명/미서명 거부와 LCI 정상/거부 테스트가 통과했습니다. 완료된 캡처는 계속 사용할 수 있으며 통과하려고 재캡처, 어댑터 제거/비활성화 또는 설정 변경을 하지 않습니다. 하드웨어 엔진은 바꾸지 않습니다.
