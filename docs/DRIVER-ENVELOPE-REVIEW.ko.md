# 기존 드라이버 보고서와 정확한 카드/칩 범위 비교

기존 개인정보 제거 보고서를 현재 proven.json과 비교합니다. 범위를 변경하거나
GPU/펌웨어/원시 이미지를 읽지 않습니다. 드라이버 캡처 해시를 완전하고 MMIO 실패가
없는 리소스 마커에 연결하고 관찰된 NVIDIA PCI/칩 쌍을 찾아 NVGOP 버전/해시를
전역 및 카드/칩 목록 모두와 비교합니다. 전역 일치만으로 카드별 조건을 통과하지 않습니다.

기존 EDID 행의 listed_nvgop_code=false는 NVGOP 비교가 적용되지 않았다는 뜻입니다.
이 소스에는 EDID 전역 허용 목록이 없습니다. 이를 "미등재 EDID"나 EDID 목록 허용
차단으로 해석하지 마세요. EDID 역할/이미지/Stop/코드 및 전체 토폴로지 검사는
make-profile.py에 별도로 남습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\research\profile\test-driver-envelope.ps1
```
기존 리소스 report.json과 driver-review.json 또는 통합 resource-files.json 경로를
입력합니다. 기존 Python만 사용합니다. 예상 결과는 driver-envelope.json이며 요청 시
검토한 JSON만 반환합니다. -OutputRoot로 기존 로컬 폴더를 지정할 수 있습니다.
알 수 없음/불일치/오류 시 원본 보존 후 중지하며 파일 대체, 프로필 생성, 설치,
설정 변경, 캡처 또는 부팅을 하지 않습니다.

제공된 문서의 로컬 계산:19 GA1062504/NVGOP6000a는 전역 목록에는 있으나 해당
카드/칩 코드 표 밖입니다.114 GA1062504/60010과31 GA1022204/60009는 코드 쌍 표에
일치합니다. 코드 쌍 일치는 소유권/해제, 서명 신뢰, 전체 프로필 허용 또는 하드웨어를
검증하지 않습니다. 여기서 원시 기여자 이미지 해시를 독립적으로 다시 계산하지 않았습니다.
이미 제공된 보고서로 계산했으므로 소유자가 확인용 재실행할 필요는 없습니다.

테스트는 다른 카드의 전역 일치, 정상 코드 쌍/통합 입력, 잘못된 코드, 캡처 해시,
범위, 불완전/MMIO/잘림/중복/알 수 없음 거부를 확인합니다. 테스트 메서드3개,
실제19/114/31 보고서 및 PowerShell 출력 검증을 통과했습니다.
