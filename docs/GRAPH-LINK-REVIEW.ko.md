# 기존 그래프 관계 검토

기존 graph-summary.json만 사용합니다. 새 캡처, 부팅, 설정 변경, 설치는 하지 않습니다.
레코드를 핸들과 프로토콜별로 구분합니다. 같은 핸들의 PCI/GOP 또는 PCI I/O의
BY_CHILD_CONTROLLER 연결만 GOP 관계로 내보냅니다. 다른 프로토콜의 연결은
인정하지 않습니다. 알 수 없거나 모호한 관계는 그대로 남으며 장치 부재 또는
물리적 MUX 배선의 증거가 아닙니다. 핸들 주소, 경로, 임의 입력 문구는 내보내지
않습니다. 캡처 해시는 입력 요약의 주장으로 복사되며 원시 로그나 하드웨어에
대해 다시 검증한 값이 아닙니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\research\profile\test-graph-links.ps1
```
기존 요약 파일 경로를 입력합니다. 기존 Python을 사용하며 컴파일러나 관리자 권한은
필요하지 않습니다. 결과는 새 Documents 폴더의 graph-links.json입니다.
-OutputRoot로 기존 로컬 쓰기 가능 폴더를 지정할 수 있습니다. 요청 시 검토한 JSON만
반환합니다. 원본은 변경하지 않습니다. 불완전, 미해결, 모호함 또는 오류 시 중지하고
결과를 보고합니다. EFI 부팅을 반복하지 않습니다. 물리 배선, 해제, 하드웨어 검증 및
쓰기 허용 플래그는 모두 false입니다.

로컬 테스트는 프로토콜 분리, 자식 연결 누락, 모호함, 중복 핸들, 불완전 캡처,
범위 및 크기 거부를 확인합니다. 제공된130 요약은 IntelA7A8의 단일 PCI-I/O
자식 연결을 보이며173은 이 제한된 규칙에서 미해결입니다. 두 소유자는 별도로
Windows 직접 복귀를 보고했습니다. Ada MMIO/잠금 해제 또는 새 리소스 캡처를
허용하지 않습니다.

## Device Path 드라이버-자식 관찰

별도 device_path_driver_child_status는 Device Path BY_CHILD_CONTROLLER 연결의
0이 아닌 에이전트가 유일한 PCI-I/O BY_DRIVER 소유자와 같을 때만 보고합니다.
소유자의 컨트롤러는 자신이고 count1이며 자식 연결도 count1이어야 합니다.
다른 에이전트, 중복/누락 소유자, 잘못된 속성/횟수는 미해결로 남습니다.
이는 make-profile.py의 관계 규칙을 반영하지만 전체 경로/콘솔/이미지/리소스
검증을 수행하지 않습니다. 기존 PCI-I/O 전용 상태는 별도로 유지합니다.
173은 기존 상태가 미해결인 동시에 새 필드가 NVIDIA 어댑터0의
unique-agent-matched-link입니다. 이미 제공한 요약으로 계산했으므로 새 캡처나
소유자 재실행은 필요하지 않습니다. 로컬 회귀 5개와 실제 요약 실행을 통과했습니다.

## 알 수 없는 ROOT/SWD 디스플레이 ID

준비 단계는 ROOT/SWD를 조용히 제외하지 않고 모든 비PCI 디스플레이에 명시적
검토 ID를 요구합니다. 구성 스키마는 넓은 ROOT/SWD 예외를 계속 금지합니다.
기존의 좁게 고정된 서명 LCI 예외는 유지하며 누락/중복/잘못된 드라이버 정보는
거부합니다. 서명 여부만으로 ROOT/SWD가 알려진 ID가 되지 않습니다. 검사를
통과하려고 어댑터를 제거/비활성화하거나 디스플레이/설정을 변경하지 마세요.
소스 검토가 끝날 때까지 준비를 중지합니다.

기존 test-x99-graph-preparation.ps1 모의 테스트는 ROOT, SWD, 보고된 Punktfunk
버전의 서명/미서명 상태 및 기존 LCI 정상/거부 사례를 포함합니다. 실제 장치를
조회하거나 준비하지 않습니다. 준비 거부만 변경하며 펌웨어 엔진, 호환성, 소유권
또는 잠금 해제 허용은 변경하지 않습니다.
