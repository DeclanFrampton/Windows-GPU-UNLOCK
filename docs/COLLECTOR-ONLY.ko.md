# Windows 수집기 전용 패키지

LICENSE, 기존 수집기/테스트 소스3개, 영어/한국어 안내 및 파일 크기/SHA256의
collector-files.json만 포함합니다. EFI 이미지, 네이티브 실행 파일, 펌웨어 자산,
GPU 실험, 의존성 또는 설치 프로그램은 없습니다. PR176의 수집기와 합성 테스트10개를
재사용하며 새 호환성 또는 백신 판정이 아닙니다.

격리된 저장소 압축 파일은 격리 상태로 두세요. 복원, Defender 해제, 예외 추가,
탐지를 피하기 위한 이름/포장 변경 또는 보호 설정 변경을 하지 마세요.
Microsoft 오탐 판정이나 제출 결과를 주장하지 않습니다. 이 최소 패키지도 차단되면
중지하고 위협 이름과 패키지 해시만 보고합니다. 다른 전달 경로 재시도나 실행을 하지
않으며 전체 보안 기록은 필요하지 않습니다.

정상 보호가 다운로드/추출을 허용하고 실행을 선택한 경우 추출 폴더의 일반 PowerShell에서:
```powershell
powershell -NoProfile -File .\tools\test-collector.ps1
```
기존 합성 회귀 검사를 먼저 실행한 뒤 Windows 인벤토리를 읽습니다. 기존 Python
애플리케이션이 필요하며 Store 설치 별칭은 거부합니다. 설치, 관리자 권한, 정책/설정
변경 또는 GPU/EFI 작업은 없습니다. 스크립트 정책이나 도구가 차단하면 변경 없이 중지합니다.

예상 PASS, collection_complete=true, can_unlock=false입니다. 출력된 Documents 폴더의
result.json과 생성된 경우 inventory.json만 검토 후 반환합니다. PARTIAL/FAILED는
검토한 작은 파일 또는 개인정보 제거 오류만 보고하고 중지합니다. 하드웨어 재시도는
없으며 인벤토리는 잠금 해제 지원을 증명하지 않습니다.

빌더는 정확한 허용 파일 목록과 재현 가능한 ZIP 메타데이터를 사용합니다. 테스트는
내용, 바이트/해시 일치, 관련 없는 파일 제외, 덮어쓰기 거부 및 재현 바이트를 확인합니다.
로컬 패키지/회귀 성공은 Defender 승인이나 모든 보안 제품의 수락 증거가 아닙니다.
